# Clairic pricing after the launch promo (fetched 2026-11-28)

Fetched 2026-11-28 with `curl` (the pages' `index.md` form) and the Workers AI changelog RSS feed. The quotes below are
verbatim; tables are cut to the Clairic rows and the lines needed to read them. Compare the
[model page saved 2026-11-21](model-page-2026-11-21.md).

## Summary

- **From 2026-12-01: $0.24 per M input tokens** (21,818 neurons per M). Promo until then: $0.10 per M (9,091 neurons).
- Billed in **neurons** at $0.011 per 1,000 neurons. The per-token price is the same charge shown in dollars.
- **Input tokens only.** No output-token charge: Clairic generates no tokens.
- **Images are converted to input tokens:** one token per 32×32 patch plus 2 markers. They are billed once per pass,
  together with the `state`. Our live calls showed one image copy per field instead (see
  [clairic-field-schema](../../wiki/clairic-field-schema.md), "Live calls"). That count is measured; the docs do not say it.
- The model page, the pricing page and the 2026-11-21 copy all agree on $0.10 → $0.24 from December 1, 2026. Nothing
  has changed since 2026-11-21.
- The changelog has no entry about the promo ending. The launch post (2026-10-19) gives only the $0.10 price.
- New since 2026-11-21: the pricing page lists `@cf/cloudflare/clairic-flash` at $0.10 per M, which "stays" at that
  price. The Clairic model page does not mention it. This repo does not use it, and its quality is untested.

## 1. Model page

URL: https://developers.cloudflare.com/workers-ai/models/clairic/ (fetched as `…/clairic/index.md`)

> - 58% off until Dec 1

> **Launch promo:** Clairic is 58% off at $0.10 per M input tokens until December 1, 2026. The standard price of $0.24
> per M input tokens applies from then on.

> | Unit Pricing | $0.10 per M input tokens ~~$0.24~~ Promo<br>Promotional price until December 1, 2026, then $0.24 per M input tokens. |

> How media inputs are billed
>
> Clairic converts media inputs to input tokens and bills them at the input token rate for the model. Clairic does not
> charge for output tokens. For per-model rates, refer to [pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/).
>
> Clairic answers each `text` field in its own pass. Other fields share a pass, and Clairic splits fields that do not
> fit beside the `state` and images in one pass across more passes. Every pass includes the full `state` and all
> images, so Clairic bills their tokens once per pass. `usage.passes` reports the number of passes.
>
> Clairic tokenizes images as follows:
>
> 1. **Resize**: Clairic keeps the image aspect ratio, but:
>    - Rounds each side to a multiple of 32 pixels.
>    - Scales up images with an area under about 65,000 pixels (256x256) to reach that area.
>    - Does not scale down larger images.
> 2. **Count patches**: Each 32x32-pixel block is one token: `tokens = (width / 32) x (height / 32)`.
> 3. **Add markers**: Clairic adds two tokens to mark where the image starts and ends.

## Per 1,000 screenshots

This uses the method in [clairic-field-schema](../../wiki/clairic-field-schema.md) ("Cost per full-screen
screenshot") and [ui-polish](../../wiki/ui-polish.md) (`ClairicPricing`). The measured input for a 1280×800 screenshot
is 1,242 schema tokens + 7 fields × 1,000 image tokens = 8,242 tokens. 1,000 screenshots = 8.242 M input tokens.

| Price | Per 1,000 (1280 long side) | Per 1,000 (1024: 5,722 tokens) |
|---|---|---|
| Promo $0.10/M (until 2026-12-01) | 8.242 × 0.10 = $0.824 | 5.722 × 0.10 = $0.572 |
| From 2026-12-01, $0.24/M | 8.242 × 0.24 = **$1.978** | 5.722 × 0.24 = $1.373 |
| Same, in neurons | 8.242 × 21,818 = 179,824 neurons × $0.011/1,000 = $1.978 | |

Free allocation (Cloudflare's whole-account Workers AI quota, shared with other models): from 2026-12-01 one
full-screen screenshot is 8,242 × 21,818 / 1e6 ≈ 180 neurons, so 10,000 free neurons per day cover about 55
screenshots per day (about 133 at the promo rate).
