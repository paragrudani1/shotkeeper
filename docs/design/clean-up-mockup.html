Clean Up

Wave 4 mockup for review. Static; 1:1; each state in light, then dark. The window is drawn at its default 680 pt width. Design note: docs/design/clean-up.md. CI snapshots of the real SwiftUI views stay the acceptance check.

One bold element: the stack of ticked thumbnails in the footer, which reappears as the confirmation's icon and in the toasts. Everything else is a native window, list, checkboxes, picker and alert.

The window: both sections, ticks and Keep

Duplicate extras come ticked; never-opened screenshots don't. One thumbnail per group, because the copies are identical; the folder is what tells them apart. The selected copy shows Keep This Copy (⌘K). The footer stack is the one bold element: it shows what is ticked as pictures, and the same stack becomes the confirmation's icon and the toast's thumbnail.
