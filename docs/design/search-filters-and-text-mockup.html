Copy Text: every text state on the preview image

The badge and its result pills live on the image, in the place macOS puts Live Text. A screenshot that was never read looks like Ready; pressing it reads, then copies.

Keys

  • ⌘D date picker, ⌘S source picker. In a picker: ↑↓ move, ↩ choose, ⌫ clear that filter, esc close.
  • esc with no picker open clears the words and every filter, then closes the panel.
  • ⇧⌘C copies the selected screenshot’s text. ⌘C still copies the image.
